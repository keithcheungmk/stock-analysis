Thesis

合約支柱已經驗證。Q4 GAAP AI Cloud US$70.5m（+110% QoQ）首次超過 Bitcoin US$66.7m，佔營收約 51%。Horizon 1 已交付並被 Microsoft 接受。呢啲係 8-K／10-K 入帳同官方確認，唔使賭社媒。

計費仍然只係部分成立。GAAP AI 年化約 US$282m，只約佔 contracted ARR US$4bn 嘅 7%。operating ARR US$1bn 截至 2026-08-26，官方腳註寫明 NON-GAAP，唔等於損益表。Headline 營收 US$137.2m、YoY −27%，轉型季唔好當成雲公司規模。

FCF 同自我融資未成立。Q4 研究 FCF ≈ −US$167m，正 OCF 幾乎係客戶預付。最大裂痕係用發股 US$2.11bn、可轉債 US$3.00bn 去 bridging。無受限現金 US$5.90B 仍低過有息負債 US$7.84B；F1 紅線 1 FAIL（非正式 50／130）。

現價相對 Base 溢價約 +1%（US$40.53 vs US$40），接近公允，唔好加倉。續抱 1,080 股 @ ~US$60；浮虧約 32% 係沉沒成本。成本要靠 Bull US$80 先回本，唔好喺約等於 Base 嘅價位攤薄。
