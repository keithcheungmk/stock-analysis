板塊三：Investment Memo

Bull Case

Defense Tech + Space backlog 轉化，毛利率企穩 25%+，Adj. EBITDA 轉正，FY 指引達標。

Bear Case

合約延期、整合成本再爆、再融資稀釋；增長故事失真。

行動

長期觀察。業務改善值得跟；現價未過現金流測試。下一步可做 Valuation，但唔好追。
