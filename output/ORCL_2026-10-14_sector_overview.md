# Skill 0：ORCL Sector Overview（AI 雲／企業軟件）

- **數據截至：** 2026-10-14
- **定位：** 企業應用黏性＋資本密集 AI IaaS 挑戰者（vs MSFT／AMZN 超大規模；SAP 應用；IBM 低增長）

### TAM／價值鏈

- AI 訓練／推理雲、企業數據庫／ERP 上雲。TAM 明顯 >US$100B（超大規模雲＋企業軟件）。
- 價值鏈：GPU／網絡設備 → 數據中心電力／土地 → IaaS → SaaS／數據庫 → 企業客戶。Oracle 同時做 IaaS＋應用層。

### 同業角色

| 公司 | 角色 |
|---|---|
| MSFT | 自我融資質量錨 |
| AMZN AWS | IaaS 規模錨（增速對照） |
| ORCL | 斜率最快、現金流最差嘅挑戰者 |
| SAP | 輕 capex ERP |
| IBM | 低增長對照 |

### 關鍵 KPI（ORCL）

IaaS 同比、RPO、當季官方 FCF、現金／票據、ATM 實際發行、FY27 營收／EPS 指引。

### 市場誤解

1. 把 RPO／IaaS 斜率直接當成 Microsoft 質量  
2. 把 EPS beat 當成紅線解除  
3. 忽略 ATM 已發生嘅稀釋
