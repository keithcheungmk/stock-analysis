# Skill 0：發射 × Starlink Connectivity × AI Compute 賽道地圖

- **賽道：** 可重複使用發射、LEO 衛星寬頻／流動通訊、以及垂直整合 AI 算力基礎設施
- **焦點公司：** SPCX（Space Exploration Technologies Corp.）；對照 RKLB、RDW；AI 線參考 CRWV 作類比標尺
- **數據截至：** 2026-08-21；現價 yfinance delayed／previous close US$135.86（America/New_York）
- **下一步：** SPCX 值得入 Framework 1；純發射挑戰者（RKLB）同國防太空系統（RDW）唔係同質對手

## 一句話定義

呢個賽道賣嘅唔係「火箭表演」，而係**把質量送上軌道、再喺軌道上賣連線同算力**：發射係入口，Starlink／Starshield 係現金引擎，AI compute（含 xAI／雲服務協議）係第二條資本密集增長曲線。

## TAM / SAM / SOM

| 口徑 | 合理範圍 | 容易誇大嘅地方 |
|---|---|---|
| TAM | 全球發射、衛星通訊、國防太空、AI 數據中心／GPU 雲合計以千億至萬億美元計（多層疊加） | 把「成個太空經濟」或「成個 AI 經濟」當成交收 |
| SAM | 可重複發射主導嘅 LEO 部署、企業／政府衛星通訊、hyperscale／neocloud 可外購嘅 GPU 產能 | 假設所有發射同通訊都由單一供應商獨佔；假設所有 AI capex 都轉成 SPCX 收入 |
| SOM（3–5 年） | Starlink 用戶／ARPU、政府 Starshield 多年合約、已簽約 Cloud Services、實際交付 GW | 把 backlog／contracted sales 當已入帳；把 Cursor 收購敘事當即期盈利 |

**管理層／市場 TAM 風險：** Q2 官方講 AI Cloud Services Agreements **US$14.1B contracted sales**、backlog **US$47.5B**、現金＋有價證券約 **US$100B**。合理投資口徑係：**已入帳分部收入 + 可驗證用戶／產能**，而唔係契約面值或敘事倍數。

## 產業鏈同價值捕獲

1. **發射（Launch）** — 決定成本到軌道；SPCX 主導；高 R&D（Starship）；客戶發射同內部 Starlink 發射並存。
2. **衛星製造／星座運營（Connectivity）** — Starlink 訂閱＋企業／政府；目前唯一穩定正營業利潤分部。
3. **國防／安全（Starshield 等）** — 多年期、高黏性，但披露節奏受保密限制。
4. **AI 基礎設施／模型／應用** — capex 極高、GAAP 仍大虧；Adj. EBITDA 已轉正（Q2）；Cursor（Anysphere）收購隱含 US$60.0B，**2026-08-14 已交割**（約 389.3M Class A）— 敘事與稀釋／整合風險並存。
5. **資本結構（IPO／債券）** — IPO 淨所得約 US$85.7B；2026-06 另有約 US$25B 債券；決定邊個先燒得起 GW。

| 問題 | 答案 |
|---|---|
| 邊層毛利／現金貢獻最高 | Connectivity（Q2 營業利潤 US$1.66B） |
| 邊層最易商品化 | 第三方發射（長期被 Starship 成本曲線擠壓） |
| 邊層最有定價權 | 星座容量、政府安全通訊、稀缺已上架 GPU |
| 邊層最易形成護城河 | 發射節奏 + 在軌星座 + 垂直整合 |
| 邊層最受周期／CAPEX／政策打擊 | AI capex、頻譜／出口管制、發射牌照與環境審批 |

## 市場可能錯判

1. 把 SPCX 當「純發射股」或「純 AI 股」——實際係三條曲線，估值語言唔同。
2. 用 RKLB／RDW 嘅 P/S 直接硬套 SPCX——規模同現金流結構差一個數量級。
3. 把 Adj. EBITDA 當自由現金流——AI capex 令 FCF 仍可以極負。
4. 忽略控制權／關聯方（xAI、X）同大型收購對 gross 稀釋同整合風險。
