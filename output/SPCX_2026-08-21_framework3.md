## 承接前提（3–5 句）

SPCX 係「發射入口 + Starlink 現金引擎 + AI 高 capex 期權」嘅平台型資產，唔係純發射股。商業質量最強喺 Connectivity 盈利同星座規模；最大風險係 AI／Starship 投資令 FCF 極負同治理／大型收購稀釋。估值最敏感變數係：（1）Starlink 用戶×ARPU；（2）AI 可持續雲收入；（3）市場肯畀幾多平台溢價（P/S 或多段 SOTP）。

## 主估值方法

**主方法：三分部 Sum-of-the-Parts（SOTP）＋情景 P/S 校準**  
**唔用：** 單一 trailing P/E（仍虧損）。Forward P/E（yfinance ~75×）只作輔助，唔作建倉唯一錨。

粗略已入帳年化營收假設（研究情景，非指引）：約 US$28–32B（反映 Q2 運行速率同 H1 基數，唔等於公司指引）。

| 分部 | Base 年化收入假設 | Base 倍數語言 | Base 隱含價值 |
|---|---:|---|---:|
| Connectivity | US$18B | 12× 銷售（訂閱／高利潤） | US$216B |
| Space | US$4B | 8×（增長但虧損） | US$32B |
| AI | US$10B | 15×（高增長虧損雲） | US$150B |
| **合計企業／股本粗值** | | | **約 US$400B** |

現市值約 US$1.79T ≈ Base SOTP 嘅 **~4.6×**，即市場已 price in 遠高於近端已入帳收入嘅長期壟斷／AI 可選性。

## 現價已經反映什麼

US$135.86／~US$1.79T 已經反映：**全球發射主導權 + Starlink 長期訂閱壟斷敘事 + AI／xAI 可選性**，而唔係「近端 FCF 折現」。對 Base 情景仍有大幅溢價 → **現價偏貴（research view）**。
