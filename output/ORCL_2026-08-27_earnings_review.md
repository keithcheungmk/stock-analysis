# Skill 8：ORCL Earnings Preview — FY2027-Q1

### Earnings Preview 結論

- **事件判定：** 高風險高彈性（對 FCF／融資叙事）；對 EPS 本身較接近「預期已高」
- **市場在賭什麼：** 唔係再確認 IaaS 好快——呢點 Q4 已經官方化。市場賭 **capex 同現金流有冇失控、ATM 會唔會開印、US$90B 故仔仲信唔信。**
- **核心結論：** 真超預期＝當季官方 FCF ≥ 0（或明顯收窄）＋IaaS 仍大幅快過 Azure／AWS＋ATM 實際為零＋指引守住。只交 non-GAAP EPS 落喺 US$1.72–1.76 區間、營收 +27–29%，係**普通符合**，唔夠翻案紅線。

### 市場預期與敏感點

- **主敘事：** 增長真實、資產負債表令人恐懼；股價已自 US$345.72 落到約 US$148。
- **已 price in：** Q4 紀錄雲數字、RPO US$638B、FY27 再籌約 US$40B、S&P BBB−（第三方）。
- **最敏感 3 個變量：**（1）當季 FCF／capex；（2）IaaS 同 RPO 確認節奏；（3）股數／ATM。次敏感：利息支出、Cloud 成本率。
- **共識（yfinance，第三方）：** EPS average 約 US$1.74（官方指引 US$1.72–1.76）；收入 average 約 US$19.13B。官方 Q1 營收 +27–29% 對上年 Q1 US$14,926m → 約 **US$18.96–19.26B**，共識大致貼住指引中間。
- **日期：** yfinance 日曆 2026-09-10；IR 未見獨立定日新聞稿 → 時點 `unverified`。

### Bull / Base / Bear 反應地圖

- **Bull：** IaaS 繼續接近翻倍或仍 +70% 以上；當季 FCF 轉正或接近零；ATM 未動；重申 US$90B／US$8.05。市場可能開始交易「紅線可解除」——呢個先係真彈性。股價 theoretically 對住 F3 Bull ~US$180，但單日反應取決於 FCF 句子。
- **Base：** 營收同 EPS 落喺指引內；IaaS 仍然快；FCF 仍負但唔惡化到 Q2／Q3 嗰種 −US$10B；融資語言不變。股價可能波動但 thesis 停喺 Weakening。**唔翻案 FAIL。**
- **Bear：** FCF 再塌、capex 指引（若有）上修、ATM 啟動、或下修全年。交易 F3 Bear ~US$80 叙事。任何「EPS beat 但現金流更差」都係低質量。

### 事件風險

- **最大 upside surprise：** 單季 FCF 轉正，或披露預付大幅增加令 OCF 明顯高過 capex。
- **最大 downside：** 融資失信（calendar 2026 再發債）、大合約延期、成本率同利息同時惡化。
- **易誤導 headline：** EPS beat、RPO 再創新高、管理層語氣樂觀、第三方客戶名。
- **Skill 7：** 財報前唔建議賣無保護 put／call；IV 會高、方向係 FCF 唔係 EPS。

### 財報前行動

- **建議動作：不追高／僅觀察**（持倉未確認；唔寫減倉）
- **理由：** F1 FAIL，事件風險不對稱，EPS 符合唔夠翻案。
- **哪個結果出現後應立刻重評：** 10-Q 年累計現金流一出，即刻重算單季 FCF——若 ≥ 0，先重開 F1 紅線 1，而唔係即場改成 PASS。
